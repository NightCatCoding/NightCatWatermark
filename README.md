# NightCat Watermark

一鍵為圖片添加水印，保護你的版權。

支持兩種模式：

- **明水印** — 肉眼可見的文字浮水印，震懾盜圖
- **暗水印** — 完全隱形的版權標識，基於深度學習，抗壓縮、抗縮放、抗裁剪

![效果預覽](app/ui/assets/light_watermarked_blind-200.png)

---

## 功能特點

### 明水印

- 自定義文字內容、字體大小
- 調整透明度、傾斜角度
- 自定義文字顏色
- 自定義水平與垂直間距
- 支持批量處理多張圖片

### 暗水印（TrustMark 引擎）

- 深度學習嵌入，肉眼完全不可見（PSNR 43-45 dB）
- 密碼加密保護，無密碼無法提取
- 抗 JPEG 壓縮（任意質量等級）
- 抗圖片縮放（50% 縮放後仍可提取）
- 抗裁剪（約 20% 面積裁剪後仍可提取）
- 抗色彩調整（亮度、對比度、濾鏡）
- 抗截圖與社交媒體二次壓縮
- 支持 PNG、JPEG、WebP 格式輸出
- 提取時只需密碼，無需記錄任何額外參數

## 使用教學

### 添加明水印

1. 打開軟件，進入「製作水印」頁面
2. 點擊「選擇圖片」添加要處理的圖片（支持批量）
3. 切換到「明水印」標籤，啟用明水印
4. 輸入水印文字，根據需要調整字體大小、透明度、角度、顏色、間距
5. 設置輸出目錄
6. 點擊「開始處理」

### 添加暗水印

1. 進入「製作水印」頁面
2. 選擇圖片並設置輸出目錄
3. 切換到「暗水印」標籤，啟用暗水印
4. 輸入加密密碼
5. 輸入隱藏信息（最多 6 個 ASCII 字符，例如 `NC2025`）
6. 點擊「開始處理」
7. 完成 — 只需記住密碼即可

### 提取暗水印

1. 進入「解析水印」頁面
2. 拖入或選擇要解析的圖片（支持 PNG、JPEG、WebP）
3. 輸入嵌入時使用的密碼
4. 點擊「開始提取」
5. 查看提取結果

## 暗水印使用須知

### 容量限制

暗水印使用 TrustMark 引擎，有效負載為 100 位元。在密碼加密模式下，每個字節的原文會被編碼為 2 個十六進位字符，因此實際可嵌入文字的上限如下：

| 場景      | 最大長度          | 示例                         |
|---------|---------------|----------------------------|
| 有密碼（推薦） | 6 個 ASCII 字符  | `NC2025`、`User42`、`ABCxyz` |
| 無密碼     | 12 個 ASCII 字符 | `NightCat2025`             |

對於版權保護場景，6 個字符足夠嵌入短標識碼。

### 圖片尺寸要求

- 最短邊不低於 150 像素
- 無上限，已驗證 12000 像素以上的大圖

### 魯棒性

| 攻擊類型             | 是否可提取 |
|------------------|-------|
| PNG 無損壓縮         | 可以    |
| JPEG 壓縮（任意質量）    | 可以    |
| WebP 壓縮          | 可以    |
| 縮放至 50%          | 可以    |
| 裁剪約 20%          | 可以    |
| 亮度 / 對比度調整       | 可以    |
| 色彩濾鏡             | 可以    |
| 截圖               | 可以    |
| 社交媒體上傳後二次壓縮      | 通常可以  |
| 極低質量 JPEG（< 10%） | 可能失敗  |
| 裁剪超過 50%         | 可能失敗  |
| AI 重繪 / 修圖       | 可能失敗  |

## 常見問題

**Q: 暗水印真的看不見嗎？**
A: 是的。TrustMark 的 PSNR 達到 43-45 dB，相當於 JPEG 質量 90 的失真程度，人眼完全無法分辨。

**Q: 圖片被壓縮或縮放後還能提取嗎？**
A: 可以。這是與舊版本的最大區別 — TrustMark 基於深度學習訓練的 encoder/decoder，專門針對各種圖像變換進行了魯棒性優化。

**Q: 可以同時添加明水印和暗水印嗎？**
A: 可以，兩者互不影響。

**Q: 忘記密碼怎麼辦？**
A: 無法提取。密碼是唯一的提取憑證，請妥善保管。

**Q: 為什麼文字限制這麼短？**
A: 這是魯棒性與容量之間的物理限制。要讓水印信號能在 JPEG 壓縮、縮放、裁剪等攻擊下存活，每一位數據都需要大量冗餘編碼。6
個字符的短標識碼足以標記版權歸屬或追蹤來源。

**Q: 舊版本嵌入的水印還能提取嗎？**
A: 不能。新版本使用完全不同的算法（TrustMark vs blind_watermark），兩者不相容。
